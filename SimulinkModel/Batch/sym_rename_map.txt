# sym_rename_map.txt -- single source of truth for the symbol unification.
#
# columns (TAB separated): old <TAB> new <TAB> kind <TAB> note
#   kind: SIG = signal / line name / Goto tag / logged label
#         PAR = base-workspace parameter
#         SUB = subsystem (block) display name
# Consumers: Batch/rename_symbols.m   (rewrites CSF_Model.slx),
#            Batch/rename_text.ps1    (rewrites *.m and Results/*.csv),
#            Batch/relabel_results.m  (rewrites the labels inside Results/*.mat),
#            Batch/check_symbols.m    (pre-flight: no old symbol may survive).
# NEVER edit one consumer only: add rows here.
#
# Reference: Latex paper "Methods" (finalised).  Paper symbol -> model symbol is
# the inverse of this table.
#
# WARNING -- the appliers are NOT idempotent.  Two rows form a cycle
# (E_Afree -> E_A0, E_A0 -> E_A_ref), so running rename_symbols twice would move
# E_A0 on to E_A_ref.  rename_symbols.m refuses to run on an already-renamed
# model; check_symbols.m verifies the result.  The same applies to relabel_results
# on a dataset that already carries the new names.
